# Арт-пайплайн «СУМРАК»

## Стиль
- Oil on canvas, grimdark, near-black dungeon background.
- Warm amber torchlight from upper left, heavy chiaroscuro and vignette.
- Desaturated umber / bone / rust / blood-crimson palette; visible canvas grain.
- Monsters: square portrait, creature fills frame, no text/border/collage.
- Items: single object centered on near-black background, same lighting, no text/border/collage.

## Каталоги
- `public/images/monsters/<enemy-id>.jpg` — индивидуальные портреты существ.
- `public/images/races/<раса>-<угроза>.png` — значки монстров на карте: 8 рас × 3 угрозы (`normal`, `horror`, `catastrophe`), 512×512, прозрачный фон.
  Стиль одного набора: белая фигура с толстой чёрной обводкой, без теней и градиентов, как в образце черепа.
  Угрозы различаются только цветом заливки: `normal` — белый, `horror` — оранжевый (#ff9a2e), `catastrophe` — красный (#d8362a). Обводка чёрная во всех трёх.
  Расы и фигуры: `undead` — череп, `construct` — голова робота, `vampire` — голова вампира, `ghost` — тело призрака, `beast` — голова волка, `demon` — голова демона, `dragon` — голова дракона, `none` — голова орка.
  Картины расы показываются только на карте: все обычные монстры расы и угрозы выглядят одинаково. В бою и бестиарии — прежние индивидуальные портреты. Боссы — свои портреты (`foe-boss.jpg` и т.д.).
  Производство: 8 белых базовых значков генерируются на чистом зелёном фоне, фон вырезается в прозрачность, оранжевая и красная версии получаются перекраской белого (ImageMagick).
  Индивидуальные портреты `monsters/<enemy-id>.jpg` показываются в бою и бестиарии, а на карте — для старых карт без угрозы.
- `public/images/map/` — значки на карте: `hero.png` (герой, одна фигура для всех), `trap-<normal|poison|bleed|curse>.png` (ловушки, тип виден до срабатывания). `event-<positive|neutral|negative>.png` (события: звезда, руна в ромбе, треугольник с молнией).
  Тот же стиль, что у значков монстров: белая фигура с чёрной обводкой, прозрачный фон, 512×512, выводятся без круглой обрезки.
- `public/images/items/<item-id>.jpg` — индивидуальные иллюстрации предметов.
- Базовые портреты `public/images/foe-*.jpg` остаются как fallback и для старых существ.
- `public/images/items-atlas.jpg` остаётся только как fallback для предметов без индивидуальной картины.
- `public/images/armory/vitruvian.jpg` — силуэт экипировки в арсенале («Витрувианский человек»); гнёзда слотов расставлены по нему в `src/components/EquipmentFigure.tsx`.

## Команды
```bash
npm run art:manifest   # пересобрать src/game/artManifest.ts после добавления файлов
npm run art:check      # отчёт покрытия
npm run art:check -- --strict  # упасть, если хотя бы одному id не хватает картины
```

## Правила изображения
- Никаких символов реальных религий и культов: ни крестов, ни нимбов, ни ликов, ни облачений.
  Сюжеты — подземелье, ремесло, алхимия, звери и конструкты.
- `icon` — светский артефакт: железная табличка с пустым овальным углублением.
- `holy_water` называется «Зелье очищающего пламени»: белое пламя, никакой обрядности.

## Остаток покрытия
Покрытие завершено: у каждого существа и каждого предмета есть индивидуальная
картина, `npm run art:check -- --strict` проходит. `items-atlas.jpg` и портреты
`foe-*.jpg` оставлены как fallback на случай новых записей без арта.

# Дерево навыков архетипов (черновик)

Статус: **черновик дизайна**. Код не менялся, ничего не закоммичено.

## Структура

```
Архетип
├── Ветка 1
│   ├── Пассив
│   └── Приём (техника оружия, использует пассив)
│       ├── Усиление приёма
│       └── Новый эффект приёма
├── Ветка 2  (то же)
└── Ветка 3  (то же)
```

- Каждый узел качается от 0 до 3 очков. Ранг усиливает числа. Ниже везде: ранг 1 / 2 / 3.
- Обе части развилки («Усиление» и «Новый эффект») можно взять вместе.
- Полное дерево одного архетипа: 3 ветки × 4 узла × 3 = 36 очков. На 15 уровне доступно 10, поэтому выбор обязателен.
- Приём в каждой ветке — отдельная техника оружия архетипа. Три ветки покрывают три техники.
- Рубежи 5 и 10 и спец-приём архетипа не меняются.

---

## Варвар (СИЛ) — оружие: Секира кровавого обета

Техники: «Кровавый расчёт», «Яростный размах», «Раскол черепа».

### Ветка 1 «Ярость» — приём «Яростный размах» (два удара подряд)
- **Пассив «Озлобление».** Каждый удар врага по тебе даёт стак. Максимум стаков: 2 / 3 / 4.
- **Приём.** Тратит все стаки. Каждый удар +3% / +5% / +7% урона за стак.
- **Усиление приёма.** Размах оставляет 1 / 2 / 3 стака.
- **Новый эффект приёма.** При 3+ стаках каждый удар размаха оглушает врага с шансом 10% / 15% / 20%.

### Ветка 2 «Жажда» — приём «Раскол черепа»
- **Пассив «Кровавый след».** 5% / 8% / 10% нанесённого урона возвращается здоровьем.
- **Приём.** Урон растёт на 6% за каждые 10% недостающего здоровья врага. На этом ударе «Кровавый след» работает ×2 / ×2,5 / ×3.
- **Усиление приёма.** Потолок бонуса 70% / 80% / 90% (вместо 60%).
- **Новый эффект приёма.** Удар накладывает кровотечение на 2 / 3 / 4 раунда.

### Ветка 3 «Замах» — приём «Кровавый расчёт»
- **Пассив «Тяжёлый замах».** Если в прошлом ходу ты стоял в защите, первый удар в этом ходу +15% / +25% / +35% урона.
- **Приём.** Урон оружия + 3×СИЛ, +6% за каждые 10% недостающего здоровья. Получает бонус замаха. Каждый ранг приёма добавляет +0,5×СИЛ.
- **Усиление приёма.** Бонус замаха для этого приёма +5% / +10% / +15%.
- **Новый эффект приёма.** При полном замахе враг пропускает следующий ход с шансом 20% / 30% / 40%.

## Бастион (СИЛ) — оружие: Булава бастиона

Техники: «Стена щитов», «Ответ бастиона», «Приговор лат».

### Ветка 1 «Стена» — приём «Стена щитов» (Защита на 2 хода, +4 брони до конца боя)
- **Пассив «Упор».** Каждый ход в защите подряд +2 / +3 / +4 брони (максимум +6 / +9 / +12). Атака сбрасывает.
- **Приём.** Тратит накопленную броню Упора: щит = броня Упора ×0,5 / ×0,75 / ×1, он поглощает урон первым.
- **Усиление приёма.** Броня до конца боя сверх +4: +1 / +2 / +3.
- **Новый эффект приёма.** Удар врага по твоей защите оглушает его с шансом 10% / 20% / 30%.

### Ветка 2 «Ответ» — приём «Ответ бастиона» (урон + 2×СИЛ, броня переходит в урон, включает Защиту)
- **Пассив «Тяжесть».** За каждые 10 брони +2% / +3% / +4% урона твоих ударов.
- **Приём.** Броня переводится в урон с 50%. Бонус Тяжести добавляется к этим 50% на этом ударе.
- **Усиление приёма.** Доля брони в уроне 60% / 70% / 80% (вместо 50%).
- **Новый эффект приёма.** Враг получает −1 / −2 / −3 брони на 2 раунда.

### Ветка 3 «Приговор» — приём «Приговор лат» (урон + 2,2×СИЛ, броня +75% к урону)
- **Пассив «Шипы».** Каждый физический удар врага даёт стак шипов. Максимум стаков: 3 / 4 / 5. Стаки держатся до конца боя.
- **Приём.** Тратит все стаки: +5% к броне-урону за стак.
- **Усиление приёма.** Приём оставляет 1 / 2 / 3 стака.
- **Новый эффект приёма.** Удар накладывает «Сломанную броню»: −2 / −3 / −4 брони врагу на 2 раунда.

## Ассасин (ЛОВ) — оружие: Стилет

Техники: «Метка смерти», «Парные клыки», «Удар открытия».

### Ветка 1 «Чутьё» — приём «Метка смерти» (крит гарантирован 2 раунда)
- **Пассив «Чутьё».** Каждый критический удар даёт стак (максимум 3 / 4 / 5). Каждый стак +2% шанса крита.
- **Приём.** Тратит все стаки: +4% урона за стак.
- **Усиление приёма.** Крит гарантирован 3 / 4 / 5 раундов (вместо 2).
- **Новый эффект приёма.** После окончания метки первый крит по врагу с шансом 25% / 40% / 60% срабатывает ещё раз.

### Ветка 2 «Выпад» — приём «Парные клыки» (два удара подряд)
- **Пассив «Разгон».** Если в прошлом ходу ты атаковал, первый удар в этом ходу +10% / +15% / +20% урона.
- **Приём.** Оба удара получают бонус Разгона, если он активен.
- **Усиление приёма.** Второй удар +20% / +30% / +40% урона.
- **Новый эффект приёма.** Каждый удар накладывает кровотечение на 1 / 2 / 3 раунда.

### Ветка 3 «Тихий шаг» — приём «Удар открытия» (урон ×2 в первые 2 раунда)
- **Пассив «Тихий шаг».** В первые 2 раунда враг промахивается по тебе с шансом 10% / 15% / 20%.
- **Приём.** Если в эти раунды враг промахнулся по тебе, следующий «Удар открытия» критует.
- **Усиление приёма.** Длительность ×2 → первые 3 / 4 / 5 раундов.
- **Новый эффект приёма.** Враг получает +5% / +10% / +15% урона от всех ударов на 2 раунда.

## Дуэлянт (ЛОВ) — оружие: Кусарикама

Техники: «Теневой захват», «Ядовитая цепь», «Встречный выпад».

### Ветка 1 «Тень на ране» — приём «Теневой захват» (+10% урона за негативный эффект на враге, до 40%)
- **Пассив «Тень на ране».** Каждый негативный эффект на враге даёт 1 стак комбо (максимум 3 / 4 / 5).
- **Приём.** Каждый стак комбо тоже считается как негативный эффект: +10% урона за стак сверх обычного бонуса.
- **Усиление приёма.** Потолок бонуса 40% → 50% / 60% / 70%.
- **Новый эффект приёма.** Захват оглушает врага на 1 ход с шансом 10% / 20% / 30%.

### Ветка 2 «Яд на клинке» — приём «Ядовитая цепь» (отравление 3 раунда)
- **Пассив «Яд на клинке».** Каждая контратака отравляет врага на 1 раунд: 2% / 3% / 4% макс. ОЗ за ход.
- **Приём.** Если враг уже отравлен, срок цепи продлевается на 1 / 2 / 3 раунда.
- **Усиление приёма.** Отравление цепи +1% / +2% / +3% урона за ход.
- **Новый эффект приёма.** Отравленный враг пропускает приём в свой ход с шансом 10% / 15% / 20%.

### Ветка 3 «Выжидание» — приём «Встречный выпад» (контратака, если враг атаковал в прошлом раунде)
- **Пассив «Выжидание».** Если в прошлом раунде ты не атаковал, первый удар +10% / +15% / +20% урона.
- **Приём.** Выпад получает бонус Выжидания при контратаке.
- **Усиление приёма.** Контратака не тратит перезарядку.
- **Новый эффект приёма.** Контратака оглушает врага на 1 ход с шансом 10% / 20% / 30%.

## Колдун (ИНТ) — оружие: Скипетр пакта

Техники: «Отток пакта», «Печать проклятия», «Реприза души».

### Ветка 1 «Запас крови» — приём «Отток пакта» (лечит 25%, откат −1)
- **Пассив «Запас крови».** 10% / 15% / 20% здоровья, потраченного на приёмы, копится в запас (максимум 20% макс. ОЗ).
- **Приём.** Лечит на 25% урона и добавляет весь запас к лечению. Запас тратится.
- **Усиление приёма.** Лечение 30% / 35% / 40% (вместо 25%).
- **Новый эффект приёма.** Снимает 1 негативный эффект с героя с шансом 20% / 30% / 40%.

### Ветка 2 «Тёмный отпечаток» — приём «Печать проклятия» (проклятие и холод на 3 раунда)
- **Пассив «Тёмный отпечаток».** Каждый удар по проклятому врагу +2% / +3% / +4% урона приёмов.
- **Приём.** Бонус Отпечатка удваивается на этом ударе.
- **Усиление приёма.** Проклятие 4 / 5 / 6 раундов (вместо 3).
- **Новый эффект приёма.** Холод превращается в обморожение: враг пропускает ход с шансом 10% / 15% / 20%.

### Ветка 3 «Живучесть» — приём «Реприза души» (лечит 35%, откат −2)
- **Пассив «Живучесть».** При ОЗ ниже 50% урон приёмов +5% / +8% / +10%.
- **Приём.** Лечение 35% умножается на бонус Живучести.
- **Усиление приёма.** Сокращает откат на 2 / 3 / 4 (вместо 2).
- **Новый эффект приёма.** Следующий приём не тратит 3% ОЗ на плату.

## Архимаг (ИНТ) — оружие: Кадило

Техники: «Слово творения», «Слово защиты», «Буря свитков».

### Ветка 1 «Перо» — приём «Слово творения» (создаёт свиток и применяет его бесплатно)
- **Пассив «Перо».** Каждый созданный в бою свиток даёт +1% / +2% / +3% магического урона до конца боя (максимум +15% / +20% / +25%).
- **Приём.** Созданный свиток получает бонус Пера к своей силе.
- **Усиление приёма.** Второй свиток создаётся с шансом 20% / 35% / 50%.
- **Новый эффект приёма.** Применённый свиток накладывает горение на 1 / 2 / 3 раунда.

### Ветка 2 «Барьерный слой» — приём «Слово защиты» (полная защита 2 хода)
- **Пассив «Барьерный слой».** Каждый созданный свиток даёт +10 / +20 / +30 маг. барьера.
- **Приём.** Барьер сохраняется и поглощает магический урон первым, пока полная защита действует.
- **Усиление приёма.** Барьер ×1 / ×1,5 / ×2 от полученного.
- **Новый эффект приёма.** Когда защита заканчивается, враг получает горение на 2 / 3 / 4 раунда.

### Ветка 3 «Лишний свиток» — приём «Буря свитков» (создаёт 2 свитка, применяет один)
- **Пассив «Лишний свиток».** Каждый 4-й / 3-й / 2-й созданный свиток создаётся дважды.
- **Приём.** Если пассив сработал в этом ходу, создаётся третий свиток.
- **Усиление приёма.** Применяются оба свитка.
- **Новый эффект приёма.** Свитки Бури получают +1 / +2 / +3 к силе.

## Что проверить до кода

- Значения рангов 1 / 2 / 3 — черновые, их нужно сбалансировать.
- Некоторые пассивы повторяют рубежи (например, «Шипы» похожи на шипы Бастиона на рубеже 10). Нужно решить, не дублируют ли они рубежи.
- Существующий `docs/archetype-skills.md` и код веток (`SKILL_BRANCHES`, `skill_<ветка>_a/b`) описывают старую систему. Их придётся заменить после утверждения.
